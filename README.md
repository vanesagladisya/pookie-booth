# Pookie Booth 📸

Pookie Booth adalah aplikasi web photo booth yang memungkinkan pengguna merasakan pengalaman berfoto secara digital melalui browser. Aplikasi ini dibuat dengan tampilan yang menarik dan nuansa yang menyenangkan.

## ✨ Tentang Project

Project ini dikembangkan sebagai aplikasi web yang berfokus pada pengalaman pengguna dan desain antarmuka. Pookie Booth dibuat untuk mengeksplorasi pengembangan website interaktif dengan tampilan yang menarik dan mudah digunakan.

## 🛠️ Teknologi yang Digunakan

* React.js
* Vite
* JavaScript
* HTML
* CSS

## 🚀 Cara Menjalankan Project

Pastikan Node.js sudah terpasang di komputer.

1. Clone repository ini:

   ```bash
   git clone https://github.com/vanesagladisya/pookie-booth.git
   ```

2. Masuk ke folder project:

   ```bash
   cd pookie-booth
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Jalankan aplikasi:

   ```bash
   npm run dev
   ```

5. Buka alamat localhost yang muncul di terminal menggunakan browser.
